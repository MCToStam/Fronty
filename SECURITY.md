# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Fronty, please do not create a public Issue.

Instead, send a private report including:

* A description of the vulnerability
* The steps to reproduce it
* The potential impact
* Any useful information that could help fix the issue

## Contact

To report a vulnerability, use:

* GitHub Security Advisories: https://github.com/MCToStam/Fronty/security/advisories

or contact the project maintainer directly.

## Remediation Process

After receiving a report:

1. The issue will be analyzed.
2. A fix will be developed.
3. A new version may be released.
4. Contributors will be informed if necessary.
